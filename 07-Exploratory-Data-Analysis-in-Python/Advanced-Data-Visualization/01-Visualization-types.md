# Visualization Types

Different visualization types are suited for different data analysis tasks.

## Common Visualizations
- Histograms: Distribution of single variable
- Box plots: Distribution summary and outliers
- Scatter plots: Relationship between two variables
- Line charts: Trends over time
- Bar charts: Comparisons across categories

## Choosing Visualizations
- Data type consideration
- Analysis goal
- Audience consideration
- Data volume
- Story to tell

## Use Cases
- Data exploration
- Pattern identification
- Communication
- Insight presentation
- Report generation
