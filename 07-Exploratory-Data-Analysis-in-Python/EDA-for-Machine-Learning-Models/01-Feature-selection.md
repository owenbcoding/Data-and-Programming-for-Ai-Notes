# Feature Selection

Feature selection involves choosing the most relevant features for machine learning models.

## Selection Methods
- Filter methods: Statistical measures
- Wrapper methods: Model-based selection
- Embedded methods: Algorithm selection
- Dimensionality reduction
- Domain knowledge

## Selection Criteria
- Relevance to target
- Low correlation with other features
- Predictive power
- Computational efficiency
- Interpretability

## Use Cases
- Model performance improvement
- Overfitting prevention
- Computational efficiency
- Model interpretability
- Feature engineering
