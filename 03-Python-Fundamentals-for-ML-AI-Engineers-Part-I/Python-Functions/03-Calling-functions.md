# Calling Functions

Calling functions executes the code defined in the function with specific arguments.

## Function Call Syntax
Functions are called by using the function name followed by parentheses containing arguments.

## Arguments vs. Parameters
- Parameters are variables defined in function definition
- Arguments are values passed when calling the function
- The number of arguments should match parameters
- Arguments can be passed by position or name

## Return Values
Functions can return values using the `return` statement. The calling code can use or ignore the returned value.

## Function Call Types
- Positional arguments
- Keyword arguments
- Default arguments
- Variable arguments
- Keyword variable arguments

## Common Built-in Functions
- `print()` for output
- `len()` for length
- `input()` for user input
- `type()` for type checking
- `range()` for sequences
