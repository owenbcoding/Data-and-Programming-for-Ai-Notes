# Built-in Functions

Built-in functions are functions that are always available in Python without needing to import them.

## Common Built-in Functions
- `print()` for output
- `len()` for length
- `type()` for type checking
- `input()` for user input
- `range()` for sequences
- `str()`, `int()`, `float()` for type conversion
- `max()` and `min()` for extremal values
- `sum()` for summation
- `sorted()` for sorting

## Function Categories
- Mathematical functions
- String functions
- Sequence functions
- Type conversion functions
- I/O functions

## Documentation
All built-in functions have documentation accessible through the `help()` function.

## Best Practices
- Know the built-in functions available
- Check documentation for unfamiliar functions
- Use built-in functions when appropriate
- Don't recreate built-in functionality
- Consider performance implications
