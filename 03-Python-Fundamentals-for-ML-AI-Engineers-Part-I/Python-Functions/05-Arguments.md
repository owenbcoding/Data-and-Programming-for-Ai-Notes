# Arguments

Arguments are the actual values passed to a function when it is called.

## Argument Types
- Positional arguments
- Keyword arguments
- Default arguments
- Variable arguments
- Keyword variable arguments

## Positional Arguments
Arguments passed in the order that parameters are defined in the function.

## Keyword Arguments
Arguments passed using the parameter name, allowing them to be passed in any order.

## Default Arguments
Arguments that have default values and can be omitted if the default is acceptable.

## Argument Matching
Python matches arguments to parameters based on position or keyword names, ensuring the function receives the expected values.
