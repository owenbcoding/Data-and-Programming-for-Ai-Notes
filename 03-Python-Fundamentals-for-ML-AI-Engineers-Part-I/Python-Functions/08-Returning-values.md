# Returning Values

The return statement allows functions to send values back to the calling code.

## Return Statement
- `return` keyword
- Returns a value to the caller
- Ends function execution
- Can return multiple values
- Optional (functions can return None)

## Return Values
- Functions can return any type
- Can return single values
- Can return multiple values as tuples
- Can return complex data structures
- Can return None if no return specified

## None Return Value
If a function doesn't have a return statement or has a return without a value, it returns None.

## Multiple Return Values
Functions can return multiple values using tuples, which can be unpacked by the caller.
