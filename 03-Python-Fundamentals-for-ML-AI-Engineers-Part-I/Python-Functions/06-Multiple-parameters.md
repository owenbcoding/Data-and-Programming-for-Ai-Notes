# Multiple Parameters

Functions can have multiple parameters to accept multiple values when called.

## Parameter Order
- Required parameters first
- Default parameters after required
- Variable-length parameters last
- Keyword variable-length parameters at the end

## Mixed Parameter Types
Functions can combine different parameter types for flexibility and convenience.

## Argument Passing
When calling functions with multiple parameters, arguments can be passed by position or by keyword name.

## Best Practices
- Limit the number of parameters for readability
- Use descriptive parameter names
- Consider using dictionaries for many parameters
- Group related parameters
- Document the expected values
