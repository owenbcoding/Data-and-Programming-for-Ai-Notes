# What Functions Are

Functions are reusable blocks of code that perform specific tasks. They help organize code, avoid repetition, and make programs more modular and maintainable.

## Function Purpose
- Code reusability
- Organization and structure
- Abstraction of complexity
- Testing and debugging
- Collaboration and sharing

## Function Components
- Function name
- Parameters (inputs)
- Function body (code to execute)
- Return statement (output)
- Documentation (docstring)

## Function Benefits
- Avoid code duplication
- Make code more readable
- Simplify complex problems
- Enable code maintenance
- Facilitate testing

## Function Types
- Built-in functions (provided by Python)
- User-defined functions (created by programmers)
- Lambda functions (anonymous functions)
- Methods (functions attached to objects)
- Generator functions (produce sequences)
