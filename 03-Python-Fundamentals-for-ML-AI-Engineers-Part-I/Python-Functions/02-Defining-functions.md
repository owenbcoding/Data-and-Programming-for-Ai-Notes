# Defining Functions

Defining functions creates reusable blocks of code with a specific name and functionality.

## Function Definition
Functions are defined using the `def` keyword followed by the function name and parentheses.

## Function Structure
- `def` keyword
- Function name
- Parameters in parentheses
- Colon at end of definition line
- Indented function body
- Optional return statement

## Function Naming
- Use descriptive names
- Follow snake_case convention
- Use verbs for actions
- Avoid Python keywords
- Be consistent with naming

## Function Parameters
Parameters are variables listed in function definition that accept values when the function is called.

## Documentation
Functions should include docstrings that explain what the function does, its parameters, and what it returns.
