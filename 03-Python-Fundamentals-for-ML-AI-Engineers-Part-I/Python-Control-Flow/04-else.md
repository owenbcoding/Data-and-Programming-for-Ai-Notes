# else

The `else` statement provides an alternative code block to execute when the `if` condition is false.

## else Statement
The `else` statement executes its code block when the preceding `if` condition is false.

## if-else Structure
- `if` condition is tested first
- `else` executes if condition is false
- Exactly one block executes
- Both cannot execute
- Can be omitted if not needed

## Use Cases
- Binary decisions
- Error handling
- Alternative actions
- Default behavior
- Fallback options

## Nested if-else
if-else statements can be nested within each other for more complex decision logic.
