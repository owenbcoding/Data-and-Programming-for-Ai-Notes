# Nested Conditions

Nested conditions are conditional statements inside other conditional statements.

## Nested if Statements
An if statement inside another if statement creates nested conditions.

## Indentation Levels
- Each level of nesting requires additional indentation
- Consistent indentation is crucial
- Python uses indentation to define scope
- Typically 4 spaces per level
- Consistency is important

## Use Cases
- Complex decision trees
- Multiple levels of conditions
- Detailed validation
- Granular control flow
- Specific error handling

## Best Practices
- Avoid excessive nesting
- Consider flattening with logical operators
- Use functions to reduce nesting
- Keep code readable
- Document complex logic
