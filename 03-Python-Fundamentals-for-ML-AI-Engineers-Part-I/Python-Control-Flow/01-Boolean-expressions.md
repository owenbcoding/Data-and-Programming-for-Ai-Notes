# Boolean Expressions

Boolean expressions are expressions that evaluate to either True or False.

## Boolean Values
- `True` and `False` (capitalized)
- Result of comparison operations
- Result of logical operations
- Used in control flow decisions
- Foundation of conditional logic

## Comparison Operators
- `==` (equal to)
- `!=` (not equal to)
- `<` (less than)
- `>` (greater than)
- `<=` (less than or equal to)
- `>=` (greater than or equal to)

## Logical Operators
- `and` (logical AND)
- `or` (logical OR)
- `not` (logical NOT)
- Used to combine boolean expressions
- Follow precedence rules

## Truthiness
Non-boolean values can be evaluated in boolean contexts. Most values are truthy, while empty containers and zero are falsy.
