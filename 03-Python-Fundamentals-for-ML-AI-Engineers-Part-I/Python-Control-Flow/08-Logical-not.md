# Logical not

The `not` operator performs logical NOT operation on boolean values.

## not Operator
- Inverts the boolean value
- Returns True if operand is False
- Returns False if operand is True
- Has highest precedence among logical operators
- Can be applied to any expression

## Truthiness
When applied to non-boolean values, the `not` operator evaluates the truthiness of the value first.

## Use Cases
- Inverting conditions
- Negating boolean values
- Default behavior
- Error conditions
- Alternative paths

## Common Patterns
- Used with comparison operators
- Combined with and/or operators
- Used in if statement conditions
- Used in while loop conditions
- Used in boolean expressions
