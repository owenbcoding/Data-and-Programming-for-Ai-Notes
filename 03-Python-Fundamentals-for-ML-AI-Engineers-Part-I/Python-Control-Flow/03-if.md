# if

The `if` statement is used for conditional execution of code blocks.

## Basic if Statement
The `if` statement executes a block of code only if a condition is true.

## Syntax
- `if` keyword followed by condition
- Colon at end of condition line
- Indented code block
- `else` clause for alternative
- `elif` for additional conditions

## Conditional Execution
Code under an `if` statement only runs when the condition evaluates to True.

## Indentation
Python uses indentation to define code blocks. All statements in the block must be indented consistently.

## Common Use Cases
- Conditional logic
- Input validation
- Error handling
- Data filtering
- Decision making
