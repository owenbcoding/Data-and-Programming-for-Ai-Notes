# Running Python Code

## Ways to Run Python

### Interactive Mode
- **Python shell**: Type `python` in terminal
- **Immediate execution**: Execute code line by line
- **Quick testing**: Perfect for quick tests
- **Experimentation**: Try out Python features
- **Learning**: Great for learning basics

### Script Mode
- **Script files**: Save code in .py files
- **Execution**: Run with `python filename.py`
- **Reusable**: Code can be reused
- **Version control**: Track changes with git
- **Sharing**: Easy to share code

### Jupyter Notebooks
- **Interactive**: Interactive coding environment
- **Cells**: Code organized in cells
- **Visualization**: Great for data visualization
- **Documentation**: Can include markdown
- **Data science**: Popular in data science

### IDEs
- **PyCharm**: Full-featured Python IDE
- **VS Code**: Lightweight, extensible
- **Spyder**: Scientific Python IDE
- **JupyterLab**: Advanced notebook interface
- **Thonny**: Beginner-friendly IDE

## Setting Up Your Environment

### Installation
- **Official installer**: Download from python.org
- **Version**: Use Python 3.x (current version)
- **Path**: Add Python to system PATH
- **Verification**: Verify installation with `python --version`
- **Package manager**: pip included automatically

### Anaconda Distribution
- **Data science**: Includes data science libraries
- **Environment management**: Conda environments
- **Jupyter**: Includes Jupyter notebooks
- **Pre-packaged**: Ready-to-use data science environment
- **Isolation**: Separate environments for projects

### Virtual Environments
- **Isolation**: Isolate project dependencies
- **venv**: Built-in virtual environment
- **conda**: Conda environments
- **poetry**: Modern dependency management
- **Best practice**: Use virtual environments for projects

## Basic Execution

### Your First Program
```python
print("Hello, World!")
```

### Running Scripts
```bash
python hello.py
```

### Interactive Shell
```python
>>> print("Hello, World!")
Hello, World!
>>> 
```

### Jupyter Notebook
- Create a new notebook
- Type code in cell
- Press Shift+Enter to execute
- Output appears below cell
- Continue with next cell
