# Strings

Strings are sequences of characters used to represent text. In Python, strings are represented by the `str` type and are enclosed in quotes.

## Characteristics
- Sequences of characters
- Can use single or double quotes
- Can span multiple lines
- Are immutable (cannot be changed after creation)
- Support various operations and methods

## String Creation
Strings can be created using single quotes, double quotes, or triple quotes for multi-line strings.

## String Operations
Strings support concatenation (joining), repetition, slicing (extracting portions), and many built-in methods for manipulation.

## Common String Methods
- `upper()` and `lower()` for case conversion
- `strip()` for removing whitespace
- `split()` for breaking strings into lists
- `join()` for combining string lists
- `replace()` for substituting text

## String Formatting
Modern Python uses f-strings for string formatting, which allow embedding expressions directly in strings using curly braces.
