# Boolean Values

Boolean values represent truth or falsehood. In Python, they are represented by the `bool` type and have only two possible values: `True` and `False`.

## Characteristics
- Only two possible values: True and False
- Used for logical operations
- Result of comparison operations
- Control flow decisions
- Often used in conditional statements

## Boolean Operations
Booleans support logical operations like AND, OR, and NOT, which are used to combine or invert boolean values.

## Comparison Operations
Comparison operations (==, !=, <, >, <=, >=) return boolean values based on the comparison result.

## Boolean in Control Flow
Boolean values are commonly used in if statements and loops to control program flow based on conditions.

## Truthiness and Falsiness
In Python, non-boolean values can be evaluated in boolean contexts, with most values being truthy and specific values (like 0, empty containers) being falsy.
