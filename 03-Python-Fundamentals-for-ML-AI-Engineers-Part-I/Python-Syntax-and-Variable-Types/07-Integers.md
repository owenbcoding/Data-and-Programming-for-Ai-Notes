# Integers

Integers are whole numbers (positive, negative, or zero) without decimal points. In Python, integers are represented by the `int` type.

## Characteristics
- Whole numbers only (no decimals)
- Can be positive, negative, or zero
- Can be arbitrarily large in Python
- Basic arithmetic operations apply
- No size limit in Python 3

## Uses
- Counting items
- Indexing (list positions)
- Loop counters
- Mathematical calculations
- Flags and status codes

## Integer Operations
Integers support all basic arithmetic operations including addition, subtraction, multiplication, division, and more specialized operations like modulo and exponentiation.

## Common Operations
- Addition and subtraction
- Multiplication and division
- Modulo (remainder of division)
- Exponentiation (powers)
- Floor division

## Type Conversion
Integers can be converted to other numeric types like floats, and strings can be converted to integers when appropriate.
