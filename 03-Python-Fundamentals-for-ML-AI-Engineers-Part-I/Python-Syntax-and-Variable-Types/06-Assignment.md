# Assignment

Assignment is the process of giving a value to a variable. In Python, the equals sign (=) is used for assignment.

## Basic Assignment
The basic assignment operator in Python is the equals sign (=). The value on the right side is assigned to the variable on the left side.

## Variable Assignment Rules
- Variable names must start with a letter or underscore
- Variable names can contain letters, numbers, and underscores
- Variable names are case-sensitive
- Variable names cannot be Python keywords
- Descriptive names are preferred over cryptic ones

## Assignment vs. Equality
Assignment (=) is different from equality (==). Assignment gives a value to a variable, while equality checks if two values are the same.

## Multiple Assignment
Python allows assigning multiple variables in a single statement, either with the same value or different values.

## Dynamic Typing
Python is dynamically typed, meaning you don't need to declare the type of a variable before assigning a value to it. The type is determined at runtime.

## Reassignment
Variables can be reassigned to different values, including values of different types.

## Common Assignment Patterns
- Single variable assignment
- Multiple variable assignment
- Unpacking assignment
- Augmented assignment
