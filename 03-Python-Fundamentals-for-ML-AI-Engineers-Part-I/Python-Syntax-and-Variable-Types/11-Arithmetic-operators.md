# Arithmetic Operators

Arithmetic operators are used to perform mathematical operations on numeric values.

## Basic Arithmetic Operators
- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Modulo (%)
- Exponentiation (**)
- Floor division (//)

## Operator Precedence
Python follows standard mathematical precedence rules: multiplication and division before addition and subtraction, with parentheses used to override precedence.

## Division Behavior
Regular division always returns a float, even when dividing integers. Floor division returns an integer by discarding the decimal part.

## Modulo Operator
The modulo operator returns the remainder of division. It's commonly used for checking divisibility and cyclical operations.

## Exponentiation
The exponentiation operator raises a number to a power. It can also be used for other mathematical operations like roots.
