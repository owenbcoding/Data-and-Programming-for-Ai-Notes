# Sorting Lists

Lists can be sorted in ascending or descending order.

## Sorting Methods
- sort() method (in-place)
- sorted() function (new list)
- Custom sorting with key
- Reverse sorting
- Complex sorting criteria

## sort() Method
- Sorts list in-place
- Default ascending order
- Modifies original list
- Returns None
- Stable sort (maintains order of equal elements)

## sorted() Function
- Returns new sorted list
- Original list unchanged
- Can sort any iterable
- Returns new list
- Can be chained

## Use Cases
- Data organization
- Numerical ordering
- Alphabetical sorting
- Custom ordering
- Data preparation
