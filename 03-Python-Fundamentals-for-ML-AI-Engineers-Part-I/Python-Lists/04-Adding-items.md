# Adding Items

Items can be added to lists using various methods.

## Adding Methods
- `append()` adds to the end
- `insert()` adds at specific position
- `extend()` adds multiple items
- Concatenation with + operator
- List comprehension for conditional adding

## append() Method
- Adds single item to end
- Modifies list in place
- Returns None
- Does not return new list
- Common and efficient

## insert() Method
- Adds item at specific index
- Shifts existing elements
- Can add at any position
- Index must be valid
- Modifies list in place

## extend() Method
- Adds multiple items
- Takes any iterable
- Modifies list in place
- Can add lists to lists
- Efficient for multiple items
