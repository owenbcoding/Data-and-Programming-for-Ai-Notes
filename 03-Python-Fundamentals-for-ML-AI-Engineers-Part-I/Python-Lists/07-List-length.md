# List Length

The length of a list can be obtained using the `len()` function.

## len() Function
- Returns number of items in list
- Counts all elements
- Includes duplicates
- Works on collections
- Returns integer

## List Size
- Number of elements in list
- Always non-negative
- Can be zero (empty list)
- Changes as list changes
- Can be used in loops

## Common Use Cases
- Looping through lists
- Validation checks
- Conditional logic
- List comparisons
- Size checks
