# Slicing

Slicing extracts a portion of a list as a new list.

## Slicing Syntax
- Uses colon notation
- Start index inclusive
- End index exclusive
- Default start is 0
- Default end is length

## Slicing Patterns
- Full slice (all elements)
- Partial slice (range of elements)
- Negative indexing
- Step values
- Reversing lists

## Common Use Cases
- Extracting subsets
- Creating copies
- Data partitioning
- Processing segments
- List manipulation
