# pop()

The `pop()` method removes and returns an item from the list.

## Basic Usage
- Removes and returns element
- Defaults to last element
- Can specify index
- Modifies list in place
- Returns removed value

## Default Behavior
- Without index, removes last element
- Returns removed value
- List becomes shorter
- Original list is modified
- Can store returned value

## Index Usage
- Can specify any valid index
- Can use negative indices
- Index must be valid
- Raises IndexError if invalid
- Removes element at that position

## Common Use Cases
- Processing items in order
- Stack/queue operations
- Random selection
- Removing known elements
- Returning and removing
