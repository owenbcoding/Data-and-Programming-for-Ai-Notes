# Accessing Elements

List elements can be accessed using their index position in the list.

## Indexing
- Zero-based indexing (first element is index 0)
- Positive indices count from the start
- Negative indices count from the end
- Index out of range raises IndexError
- Index must be integer

## Accessing Single Elements
- Use square brackets with index
- Returns the element at that position
- Can be assigned to variables
- Can be used in expressions
- Can be nested for multi-dimensional structures

## Indexing Patterns
- Single element access
- Negative indexing
- Accessing from the end
- Out of range errors
- Type of returned element

## Use Cases
- Retrieving specific values
- Processing specific items
- Conditional selection
- Data validation
- List manipulation
