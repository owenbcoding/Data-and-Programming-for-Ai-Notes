# Combining Lists

Lists can be combined in various ways to create new lists.

## Combination Methods
- Concatenation with + operator
- extend() method
- List comprehension
- Using append() in loops
- Using itertools.chain()

## Concatenation Operator
- Creates new list
- Original lists unchanged
- Can combine multiple lists
- Preserves order
- Type must match (both lists)

## extend() Method
- Modifies original list
- Adds elements from iterable
- More efficient for large lists
- In-place operation
- Returns None

## Use Cases
- Data aggregation
- List combination
- Data processing
- Merge operations
- Collection building
