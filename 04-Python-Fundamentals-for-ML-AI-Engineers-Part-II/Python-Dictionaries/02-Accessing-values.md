# Accessing Values

Dictionary values can be accessed using their keys.

## Accessing Methods
- Using square brackets with key
- Using get() method
- Direct key access
- Safe access with get()
- Default values with get()

## Key Access
- Use key in square brackets
- Returns associated value
- Raises KeyError if key not found
- Fast lookup operation
- Original dictionary unchanged

## get() Method
- Returns value if key exists
- Returns default if key not found
- Does not raise error
- Can specify default value
- Safe access method

## Use Cases
- Data lookup
- Configuration access
- Safe data retrieval
- Default values
- Error prevention
