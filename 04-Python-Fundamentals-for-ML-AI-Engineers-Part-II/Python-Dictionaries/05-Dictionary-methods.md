# Dictionary Methods

Dictionaries have many built-in methods for common operations.

## Common Methods
- `keys()` returns all keys
- `values()` returns all values
- `items()` returns key-value pairs
- `get()` safe value access
- `update()` for bulk updates

## Views
- keys() returns view of keys
- values() returns view of values
- items() returns view of key-value pairs
- Views are dynamic
- Views reflect dictionary changes

- Iterating over dictionaries
- Dictionary operations
