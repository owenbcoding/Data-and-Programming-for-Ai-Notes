# Removing Items

Items can be removed from dictionaries using various methods.

## Removal Methods
- `del` statement
- `pop()` method
- `popitem()` method
- `clear()` method
- Conditional removal

## del Statement
- Removes key-value pair
- Raises KeyError if key not found
- Modifies dictionary in place
- Cannot return value
- Simple deletion

## pop() Method
- Removes and returns value
- Returns default if key not found
- Modifies dictionary in place
- Can specify default value
- Returns removed value

## Use Cases
- Data cleanup
- Removing processed items
- Dictionary management
- Memory management
- Data filtering
