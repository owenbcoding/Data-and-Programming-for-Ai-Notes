# Adding Items

Items can be added to dictionaries by assigning values to new keys.

## Adding Methods
- Direct assignment with new key
- Using update() method
- Dictionary unpacking
- setdefault() method
- Multiple item addition

## Direct Assignment
- Use key in square brackets
- Assign value to new key
- Overwrites if key exists
- Modifies dictionary in place
- Simple and direct

## update() Method
- Updates multiple items
- Takes dictionary or iterable
- Modifies original dictionary
- Can add or update
- Returns None

## Use Cases
- Building dictionaries
- Data aggregation
- Configuration updates
- Data merging
- Dictionary construction
