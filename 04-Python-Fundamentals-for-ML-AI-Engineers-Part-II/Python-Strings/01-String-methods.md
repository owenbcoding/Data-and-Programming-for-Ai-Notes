# String Methods

String methods are functions that operate on strings and return new strings or information about the string.

## Common String Methods
- `upper()` and `lower()` for case conversion
- `strip()` for removing whitespace
- `replace()` for substituting text
- `split()` for breaking strings into lists
- `join()` for combining string lists

## Method Categories
- Case conversion methods
- Whitespace methods
- Search and replace methods
- Formatting methods
- Validation methods

## Immutability
String methods return new strings because strings are immutable. The original string is never modified.

## Use Cases
- Text cleaning
- Data validation
- Text formatting
- String manipulation
- Text processing
