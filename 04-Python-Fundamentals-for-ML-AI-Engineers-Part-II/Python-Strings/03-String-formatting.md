# String Formatting

String formatting allows you to insert values into strings in a controlled way.

## Formatting Methods
- f-strings (Python 3.6+)
- `format()` method
- % formatting (older method)
- Template strings
- Custom formatting

## f-strings
- Modern, preferred method
- Uses curly braces
- Can include expressions
- Very readable
- Fast execution

## Use Cases
- Displaying values
- Building messages
- Creating output
- Formatting data
- User communication
