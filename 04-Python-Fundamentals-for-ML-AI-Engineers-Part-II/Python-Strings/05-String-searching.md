# String Searching

String searching methods find substrings or patterns within strings.

## Search Methods
- `find()` returns index of first occurrence
- `index()` similar to find but raises error
- `rfind()` searches from right
- `count()` counts occurrences
- `in` operator for membership test

## Return Values
- Index of first occurrence
- -1 if not found (for find)
- Error if not found (for index)
- Count of occurrences
- Boolean for membership

## Use Cases
- Finding substrings
- Pattern matching
- Validation
- Data extraction
- Text analysis
