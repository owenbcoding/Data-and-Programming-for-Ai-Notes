# Writing Files

Files can be written in Python using the `open()` function with write mode and various writing methods.

## Writing Methods
- `write()` writes string to file
- `writelines()` writes list of strings
- Appending to existing files
- Using with statement for automatic closing
- Error handling for file operations

## File Modes
- `w` for writing (overwrites)
- `a` for appending
- `w+` for writing and reading
- `wb` for binary writing
- Encodings for text files

## Use Cases
- Data export
- Log files
- Configuration files
- Report generation
- Data persistence
