# Reading Files

Files can be read in Python using the `open()` function and various reading methods.

## Reading Methods
- `read()` reads entire file
- `readline()` reads one line
- `readlines()` reads all lines
- Iterating over file object
- Using with statement for automatic closing

## File Modes
- `r` for reading (default)
- `r+` for reading and writing
- `rb` for binary reading
- Encodings for text files
- Error handling for file operations

## Use Cases
- Data loading
- Configuration files
- Log files
- Text processing
- Data import
