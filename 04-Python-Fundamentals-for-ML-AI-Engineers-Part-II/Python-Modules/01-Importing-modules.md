# Importing Modules

Modules are Python files that contain Python code and can be imported into other Python files.

## Import Methods
- `import module` imports entire module
- `import module as alias` imports with alias
- `from module import name` imports specific items
- `from module import *` imports all items
- Dynamic imports with importlib

## Module Locations
- Standard library modules
- Third-party packages
- Local modules
- Module search path
- Virtual environment packages

## Use Cases
- Code organization
- Code reuse
- Namespace management
- Third-party library usage
- Project structure
