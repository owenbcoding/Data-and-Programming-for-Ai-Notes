# Portfolio Projects and Course Expectations

## Portfolio Projects Overview
Throughout this course, you will build a portfolio of practical projects that demonstrate your skills in data analysis, Python programming, and statistical thinking.

## Project Types

### Data Analysis Projects
- **U.S. Medical Insurance Costs**: Analyze real insurance data using Python
- **Movie Statistics Lab**: Apply statistical thinking to movie data
- **Coffee Shop Sales**: Use AI to analyze sales data
- **Backyard Birder's Association**: Create data visualizations

### Mathematical Projects
- **Detecting Product Defects**: Apply probability distributions
- **Sampling Distributions**: Analyze Spotify data using sampling theory
- **Image Transformations**: Use linear algebra with NumPy

### Final Portfolio Project
- Choose your own dataset and question
- Apply all learned concepts
- Create a comprehensive analysis
- Build a complete portfolio piece

## Course Expectations

### Time Commitment
- Approximately 39 hours total
- Self-paced learning
- Hands-on coding exercises
- Project-based learning

### Learning Approach
- Active participation in coding exercises
- Completion of all projects
- Engagement with quizzes and assessments

### Code Quality
- Write clean, readable code
- Follow Python best practices
- Comment your code appropriately
- Use meaningful variable names
- Structure your code logically

### Analytical Thinking
- Ask good questions about data
- Think critically about results
- Consider limitations and biases
- Validate your findings
- Communicate insights clearly

## Project Guidelines

### Data Handling
- Always inspect data before analysis
- Clean and validate datasets
- Document your data sources
- Handle missing values appropriately
- Consider ethical implications

### Analysis Process
1. Define clear questions
2. Explore the data thoroughly
3. Apply appropriate statistical methods
4. Visualize findings effectively
5. Draw justified conclusions
6. Communicate results clearly

### Portfolio Building
- Keep all project code organized
- Document your methodology
- Save visualizations and outputs
- Write clear explanations
- Create a professional presentation

## Success Criteria
