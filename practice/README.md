# Practice Folder

This folder contains practice files and exercises to reinforce Data Literacy concepts.

## File Structure

### Data Files
- `data-quality-sample.csv` - Sample dataset with intentional quality issues for practice
- `structured-data-example.json` - Example of structured data (JSON format)
- `unstructured-data-example.txt` - Example of unstructured data (text format)

### Analysis Files
- `data-bias-analysis.md` - Template and examples for analyzing data bias
- `data-validation-checklist.py` - Python code for data quality validation
- `data-types-exercise.py` - Exercises for understanding data types and structures

## How to Use These Files

### 1. Data Quality Assessment
- Open `data-quality-sample.csv` and identify quality issues
- Use `data-validation-checklist.py` as a guide for systematic validation
- Document your findings using the validation template

### 2. Data Types Practice
- Compare `structured-data-example.json` and `unstructured-data-example.txt`
- Run `data-types-exercise.py` to understand different data types
- Practice categorizing new datasets you encounter

### 3. Bias Analysis
- Read the case studies in `data-bias-analysis.md`
- Research one real-world bias example
- Use the analysis framework to assess a dataset of your choice

## Practice Exercises

### Exercise 1: Data Quality Audit
1. Load `data-quality-sample.csv`
2. Identify at least 5 quality issues
3. Categorize each issue (completeness, accuracy, consistency, etc.)
4. Propose solutions for each issue

### Exercise 2: Data Type Classification
1. Find a real dataset
2. Classify each field by data type
3. Identify any conversion challenges
4. Document the optimal structure for your use case

### Exercise 3: Bias Detection
1. Choose a dataset or algorithm case study
2. Use the bias analysis framework
3. Identify at least 2 potential bias sources
4. Propose mitigation strategies

## Adding Your Own Practice Files

- Add CSV files for data cleaning practice

- Save text files for NLP/text analysis practice
- Document your own bias analysis findings

## Integration with Course Progress

These practice files align with Module 02 (Data Literacy). As you advance to later modules, you can add corresponding practice files for:

- **Module 03-04**: Python coding practice files
- **Module 06**: Pandas data manipulation exercises
- **Module 07**: EDA visualization practice
- **Module 08**: Statistical analysis examples

## Tips for Effective Practice

1. **Start Small**: Begin with the provided sample files before moving to real data
2. **Be Systematic**: Use the checklists and templates provided
3. **Document Everything**: Keep notes on what you tried and what worked
4. **Learn from Mistakes**: Use the mistake log in the main PRACTICE.md file
5. **Apply Real Data**: Practice with datasets relevant to your interests

## File Naming Convention

When adding your own practice files, use this convention:
- `practice-{concept}.{extension}`
- Examples: `practice-cleaning.csv`, `practice-visualization.py`

This keeps the practice folder organized and easy to navigate.
