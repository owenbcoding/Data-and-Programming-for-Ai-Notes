# Probability Basics

Probability is the study of uncertainty and chance, fundamental to machine learning and AI.

## Basic Concepts
- Probability values between 0 and 1
- Sample space: All possible outcomes
- Events: Subsets of sample space
- Probability rules
- Conditional probability

## Key Rules
- Addition rule for union of events
- Multiplication rule for intersection
- Complement rule
- Independence
- Bayes' theorem

## Use Cases
- Machine learning algorithms
- Uncertainty quantification
- Risk assessment
- Decision making
- Statistical inference
