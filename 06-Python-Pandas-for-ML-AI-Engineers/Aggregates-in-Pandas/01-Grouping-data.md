# Grouping Data

Grouping data allows you to split data into groups based on criteria and apply operations to each group.

## GroupBy Operations
- Split data into groups
- Apply functions to groups
- Combine results
- Multiple grouping criteria
- Group transformations

## GroupBy Methods
- `groupby()` for grouping
- Aggregation functions
- Transformation functions
- Filtering functions
- Custom functions

## Common Aggregations
- Mean, median, mode
- Sum, count
- Min, max
- Standard deviation
- Custom aggregations

## Use Cases
- Group-wise analysis
- Category comparisons
- Time-based grouping
- Statistical analysis
- Data summarization
