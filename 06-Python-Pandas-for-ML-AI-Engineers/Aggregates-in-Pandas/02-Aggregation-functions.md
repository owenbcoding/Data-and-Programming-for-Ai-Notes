# Aggregation Functions

Aggregation functions compute summary statistics for groups or entire DataFrames.

## Common Aggregations
- `sum()` for summation
- `mean()` for average
- `median()` for median
- `min()` and `max()` for extremes
- `count()` for counting

## Statistical Aggregations
- `std()` for standard deviation
- `var()` for variance
- `quantile()` for quantiles
- `describe()` for summary statistics
- Custom aggregation functions

## Aggregation Patterns
- Single column aggregation
- Multiple column aggregation
- Group-wise aggregation
- Rolling aggregations
- Cumulative aggregations

## Use Cases
- Data summarization
- Statistical analysis
- Feature engineering
- Data reduction
- Insight generation
