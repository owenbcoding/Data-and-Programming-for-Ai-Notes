# Joining Data

Joining combines DataFrames based on their indices.

## Join Types
- Left join
- Right join
- Inner join
- Outer join
- Cross join

## Join Methods
- `join()` for index-based joins
- Merge with index
- Set operations
- Index alignment
- Hierarchical indexing

## Use Cases
- Index-based combination
- Time series joining
- Hierarchical data
- Multi-index operations
- Data alignment
