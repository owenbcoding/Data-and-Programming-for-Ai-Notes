# Series

Series is a one-dimensional labeled array in Pandas, similar to a column in a spreadsheet.

## Series Characteristics
- One-dimensional data structure
- Labeled index
- Can hold any data type
- Homogeneous data type
- Basic building block of DataFrames

## Creating Series
- From lists
- From arrays
- From dictionaries
- From scalar values
- With custom index

## Series Operations
- Mathematical operations
- Statistical operations
- Indexing and slicing
- Filtering
- Aggregation

## Use Cases
- Single column data
- Time series data
- Data analysis
- Feature engineering
- Data preparation
