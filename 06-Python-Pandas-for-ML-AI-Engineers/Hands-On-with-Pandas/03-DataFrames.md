# DataFrames

DataFrame is a two-dimensional labeled data structure in Pandas, similar to a spreadsheet or SQL table.

## DataFrame Characteristics
- Two-dimensional data structure
- Row and column labels
- Can hold different data types per column
- Heterogeneous data types
- Primary Pandas data structure

## Creating DataFrames
- From dictionaries
- From lists of lists
- From NumPy arrays
- From Series
- From CSV files

## DataFrame Operations
- Data selection
- Data filtering
- Data manipulation
- Data aggregation
- Data transformation

## Use Cases
- Tabular data
- Dataset manipulation
- Data analysis
- Data cleaning
- Machine learning data preparation
