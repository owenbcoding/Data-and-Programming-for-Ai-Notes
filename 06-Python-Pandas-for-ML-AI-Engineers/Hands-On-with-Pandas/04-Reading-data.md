# Reading Data

Pandas can read data from various file formats and sources.

## Reading Methods
- `read_csv()` for CSV files
- `read_excel()` for Excel files
- `read_json()` for JSON files
- `read_sql()` for SQL databases
- Other format readers

## Common Parameters
- File path or URL
- Column selection
- Data type specification
- Index column
- Missing value handling

## Data Sources
- Local files
- Remote URLs
- Databases
- APIs
- Cloud storage

## Use Cases
- Data import
- Data loading
- Multiple source integration
- Data pipeline building
- ETL operations
