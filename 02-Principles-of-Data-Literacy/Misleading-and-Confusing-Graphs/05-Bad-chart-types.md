# Bad Chart Types

## Understanding Inappropriate Chart Selection
Choosing the wrong chart type can make data difficult to understand, create misleading impressions, or fail to communicate the intended message effectively.

## Common Inappropriate Chart Choices

### Pie Charts for Many Categories
- **Problem**: Too many slices become unreadable
- **Example**: Pie chart with 15+ categories
- **Impact**: Impossible to distinguish slices
- **Better choice**: Bar chart
- **Guideline**: Maximum 5-7 categories for pie charts

### Line Charts for Categorical Data
- **Problem**: Implies continuous connection between categories
- **Example**: Line chart connecting product categories
- **Impact**: Misleading suggestion of relationship
- **Better choice**: Bar chart
- **Guideline**: Use line charts only for continuous data

### 3D Charts
- **Problem**: Distorts perception, hard to read
- **Example**: 3D pie chart or bar chart
- **Impact**: Misleading proportions, difficult comparison
- **Better choice**: 2D version
- **Guideline**: Avoid 3D effects unless necessary

### Radar Charts for Many Variables
- **Problem**: Too many variables create clutter
- **Example**: Radar chart with 10+ variables
- **Impact**: Impossible to interpret
- **Better choice**: Small multiples or bar charts
- **Guideline**: Maximum 5-7 variables

### Scatter Plots for Categorical Data
- **Problem**: Scatter plots require numerical data
- **Example**: Plotting categorical variables on scatter plot
- **Impact**: Meaningless visualization
- **Better choice**: Bar chart or heat map
- **Guideline**: Match chart type to data type

## Chart Type Selection Guidelines

### Data Type Matching
- **Categorical**: Bar charts, pie charts (few categories)
- **Numerical single variable**: Histograms, box plots
- **Numerical two variables**: Scatter plots
- **Time series**: Line charts
- **Geographical**: Maps

### Purpose Matching
- **Comparison**: Bar charts, box plots
- **Distribution**: Histograms, density plots
- **Relationship**: Scatter plots
- **Composition**: Pie charts, stacked bar charts
- **Trends**: Line charts

### Audience Matching
- **General audience**: Simple, familiar chart types
- **Technical audience**: Can handle complex charts
- **Executive audience**: Clear, impactful charts
- **Mixed audience**: Balance simplicity and detail
- **Expert audience**: Specialized chart types acceptable

## Common Mistakes and Solutions

### Mistake: Wrong Chart for Data Type
- **Example**: Using pie chart for time series
- **Problem**: Chart doesn't match data structure
- **Solution**: Match chart to data type
- **Guideline**: Consider data characteristics first

### Mistake: Overcomplicating Simple Data
- **Example**: Complex chart for simple comparison
- **Problem**: Unnecessary complexity
- **Solution**: Use simplest effective chart
- **Guideline**: Simpler is often better

### Mistake: Oversimplifying Complex Data
- **Example**: Simple chart for complex relationship
- **Problem**: Loses important information
- **Solution**: Use appropriate complexity
- **Guideline**: Match complexity to data complexity

### Mistake: Following Trends Blindly
- **Example**: Using trendy but inappropriate chart
- **Problem**: Style over substance
- **Solution**: Choose chart for effectiveness
- **Guideline**: Function over fashion

## Decision Framework

### Step 1: Understand Data
- **Data types**: Categorical, numerical, time, geographical
- **Data structure**: Single variable, multiple variables
- **Data volume**: Few points, many points
- **Data quality**: Clean, messy, missing values

### Step 2: Define Purpose
- **Communication goal**: What message to convey?
- **Comparison needs**: Comparing groups, time periods?
- **Analysis needs**: Exploring, confirming, presenting?
- **Audience needs**: What will audience understand?

### Step 3: Consider Constraints
- **Time**: How much time for design?
- **Tools**: What software available?
- **Skills**: What visualization skills?
- **Format**: Where will it be displayed?

### Step 4: Select Chart Type
- **Match to data**: Appropriate for data type
- **Match to purpose**: Achieves communication goal
- **Match to audience**: Appropriate complexity
- **Test alternatives**: Try different chart types

### Step 5: Refine Design
- **Simplify**: Remove unnecessary elements
- **Clarify**: Improve labels and legends
- **Test**: Verify with sample audience
- **Iterate**: Refine based on feedback

## Special Cases and Alternatives

### Many Categories
- **Problem**: Bar chart with too many categories
- **Alternative**: Group categories, use treemap
- **Solution**: Reduce categories or use alternative

### Many Variables
- **Problem**: Too many variables for single chart
- **Alternative**: Small multiples, scatter plot matrix
- **Solution**: Break into multiple charts

### Complex Relationships
- **Problem**: Single chart can't show complexity
- **Alternative**: Multiple linked charts
- **Solution**: Use dashboard approach

### Mixed Data Types
- **Problem**: Combination of categorical and numerical
- **Alternative**: Combination charts, layered charts
- **Solution**: Design custom visualization

## Accessibility Considerations

### Chart Type and Accessibility
- **Screen readers**: Some charts more accessible
- **Color blindness**: Chart type affects accessibility
- **Cognitive load**: Complex charts harder to understand

- **Multiple formats**: Chart + table
- **Clear labels**: Essential for all users

- **Simple charts**: More accessible
