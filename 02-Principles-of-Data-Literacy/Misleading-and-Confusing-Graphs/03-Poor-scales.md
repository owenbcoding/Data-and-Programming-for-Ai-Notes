# Poor Scales

## Understanding Scale Problems
Poor scale choices can distort data perception, create misleading impressions, and make accurate interpretation difficult or impossible.

## Types of Scale Problems

### Inconsistent Scales
- **Problem**: Different scales across comparable charts
- **Impact**: Impossible to make accurate comparisons
- **Example**: Quarterly sales charts with different y-axis ranges
- **Detection**: Compare axis labels across similar charts
- **Solution**: Use consistent scales for comparisons

### Non-Linear Scale Misuse
- **Problem**: Inappropriate scale type for data
- **Impact**: Distorts relationships and patterns
- **Example**: Linear data on logarithmic scale
- **Detection**: Unexpected patterns or proportions
- **Solution**: Choose appropriate scale type

### Uneven Intervals
- **Problem**: Inconsistent spacing between values
- **Impact**: Misleading visual representation
- **Example**: Uneven time intervals on time series
- **Detection**: Check axis labels and spacing
- **Solution**: Use consistent intervals

### Scale Reversal
- **Problem**: Axis direction reversed without clear indication
- **Impact**: Confusing interpretation
- **Example**: Y-axis inverted without explanation
- **Detection**: Unexpected patterns or trends
- **Solution**: Clear indication if reversal intentional

## Scale and Perception

### Visual Weight
- **Scale affects visual weight** of data
- **Large ranges make differences seem small**
- **Small ranges exaggerate differences**
- **Aspect ratio affects slope perception**
- **Cultural expectations**: Up is good, right is forward

### Comparative Perception
- **Humans compare relative sizes**
- **Scale choices affect perceived magnitude**
- **Reference points influence perception**
- **Context affects interpretation**
- **Expectations shape understanding**

### Cognitive Biases
- **Anchoring**: First reference point influences perception
- **Framing**: Scale choice frames interpretation
- **Contrast effect**: Relative comparisons
- **Magnitude neglect**: Ignore scale when focused on pattern
- **Confirmation bias**: See what expected

## Common Scale Mistakes

### Time Series Scales
- **Problem**: Inconsistent time intervals
- **Example**: Mixing months and quarters
- **Impact**: Misleading trend representation
- **Solution**: Consistent time intervals

### Categorical Scales
- **Problem**: Inappropriate ordering
- **Example**: Random category order
- **Impact**: Hard to find patterns
- **Solution**: Logical ordering (alphabetical, value, custom)

### Numerical Scales
- **Problem**: Inappropriate range
- **Example**: Too wide or too narrow
- **Impact**: Data obscured or exaggerated
- **Solution**: Appropriate range for data

### Percentage Scales
- **Problem**: Inappropriate baseline
- **Example**: Not starting at 0% or 100%
- **Impact**: Misleading proportions
- **Solution**: Appropriate percentage baseline

## Scale Selection Guidelines

### Linear Scales
- **Use when**: Data ranges are similar
- **Advantages**: Intuitive, easy to read
- **Best for**: Most common situations
- **Example**: Height, weight, temperature
- **Guideline**: Default choice unless reason to differ

### Logarithmic Scales
- **Use when**: Data spans multiple orders of magnitude
- **Advantages**: Shows wide range clearly
- **Best for**: Scientific data, exponential growth
- **Example**: Earthquake magnitude, sound intensity
- **Guideline**: Clearly label as logarithmic

### Percentage Scales
- **Use when**: Showing proportions or rates
- **Advantages**: Standardized interpretation
- **Best for**: Survey results, rates, changes
- **Example**: Response rates, growth rates
- **Guideline**: Include % symbol, clear baseline

### Index Scales
- **Use when**: Comparing different units or time periods
- **Advantages**: Enables comparison
- **Best for**: Economic indicators, performance metrics
- **Example**: Consumer price index, stock indices
- **Guideline**: Clear base period and calculation

## Detecting Poor Scales

### Visual Inspection
- **Look for**: Inconsistent spacing
- **Check**: Axis labels and values
- **Compare**: Similar charts
- **Question**: Unexpected patterns
- **Verify**: Numerical values

### Analytical Checks
- **Calculate**: Actual differences
- **Compare**: Visual vs. numerical
- **Test**: Alternative scales
- **Verify**: Scale appropriateness
- **Document**: Issues found

### Critical Questions
- **Why this scale?**
- **What would other scales show?**
- **Is this scale appropriate for the data?**
- **Are comparisons valid?**
- **Is the scale clearly indicated?**

## Best Practices

### Planning
- **Understand data**: Range, distribution, patterns
- **Know audience**: Technical understanding
- **Define purpose**: What should chart show?
- **Consider comparisons**: Will this be compared?
- **Choose appropriately**: Match scale to purpose

### Implementation
- **Consistent scales**: Across comparable charts
- **Clear labels**: Variable names and units
- **Appropriate range**: Show relevant data
- **Logical intervals**: Even spacing
- **Transparency**: Explain scale choices

### Communication
- **Explain choices**: Why this scale?
- **Provide context**: What's not shown?
- **Show alternatives**: When scale matters
- **Educate audience**: Help understanding
- **Document decisions**: Record rationale
