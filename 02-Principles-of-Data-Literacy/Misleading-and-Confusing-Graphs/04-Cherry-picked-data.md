# Cherry-Picked Data

## Understanding Cherry-Picking
Cherry-picking involves selectively presenting data that supports a particular conclusion while ignoring data that contradicts it. This creates a misleading picture of the full situation.

## Types of Cherry-Picking

### Time Period Selection
- **Problem**: Selecting specific time periods that show desired trend
- **Example**: Showing only months with positive growth
- **Impact**: Misleading trend representation
- **Detection**: Look for full time series
- **Solution**: Show complete time range

### Data Source Selection
- **Problem**: Using only data sources that support conclusion
- **Example**: Using only favorable studies
- **Impact**: Biased representation
- **Detection**: Check data sources
- **Solution**: Include all relevant sources

### Outlier Focus
- **Problem**: Focusing only on outliers that support narrative
- **Example**: Highlighting only extreme cases
- **Impact**: Misleading representation of typical cases
- **Detection**: Look at full distribution
- **Solution**: Show complete data distribution

### Group Selection
- **Problem**: Selecting only groups that show desired pattern
- **Example**: Showing only successful case studies
- **Impact**: Unrepresentative picture
- **Detection**: Check for missing groups
- **Solution**: Include all relevant groups

## How Cherry-Picking Misleads

### Creating False Patterns
- **Selective inclusion**: Creates apparent patterns
- **Missing context**: Hides contradictory evidence
- **Biased samples**: Unrepresentative picture
- **Confirmation bias**: Reinforces existing beliefs
- **Narrative control**: Shapes story to desired conclusion

### Examples
- **Climate data**: Selecting cooler years to question warming
- **Economic data**: Choosing recession periods to show decline
- **Health data**: Using only successful treatment cases
- **Business data**: Showing only profitable quarters
- **Educational data**: Selecting only improving schools

## Detecting Cherry-Picking

### Red Flags
- **Incomplete time series**: Missing time periods
- **Limited data sources**: Only favorable sources
- **Narrow group selection**: Only specific groups shown
- **Convenient start/end points**: Period chosen for effect
- **Missing context**: Contradictory data absent

### Verification Steps
- **Request full data**: Ask for complete dataset
- **Check time range**: Look for missing periods
- **Verify sources**: Check data source diversity
- **Examine groups**: Look for missing categories
- **Seek context**: Find contradictory information

### Critical Questions
- **What data is missing?**
- **Why was this time period chosen?**
- **Are there other data sources?**
- **What groups are not shown?**
- **Would different data tell a different story?**

## Best Practices for Honest Data Presentation

### Comprehensive Data
- **Complete time series**: Show full relevant range
- **Multiple sources**: Include diverse data sources
- **All groups**: Show all relevant categories
- **Full distribution**: Show complete data picture
- **Context**: Provide necessary context

### Transparent Selection
- **Explain choices**: Why this data/time period?
- **Acknowledge limitations**: What's not shown?
- **Show alternatives**: Present different views
- **Provide context**: Full background information
- **Document methodology**: Clear data selection process

### Balanced Presentation
- **Show counterexamples**: Include contradictory data
- **Present uncertainty**: Acknowledge complexity
- **Avoid overstatement**: Don't overclaim
- **Provide nuance**: Complex situations need nuance
- **Encourage critical thinking**: Invite questions

## Ethical Considerations

### Intent
- **Deliberate deception**: Unethical
- **Emphasis**: Can be appropriate with context
- **Simplification**: May be necessary for communication
- **Transparency**: Always be transparent
- **Audience**: Consider their understanding

### Professional Standards
- **Completeness**: Strive for complete presentation
- **Context**: Provide necessary background
- **Balance**: Show multiple perspectives
- **Honesty**: Acknowledge limitations
- **Integrity**: Maintain professional integrity

## Prevention Strategies

### Data Collection
- **Predefine analysis plan**: Before seeing data
- **Use systematic methods**: Avoid selective inclusion
- **Document decisions**: Record selection criteria
- **Peer review**: Get feedback on data selection
- **Blind analysis**: When possible

### Analysis Process
- **Pre-register analysis**: Document planned analysis
- **Include all data**: Unless clear exclusion criteria
- **Test sensitivity**: How robust to data inclusion?
- **Report all tests**: Not just significant ones
- **Share data**: Enable verification

### Communication
- **Show full data**: When possible
- **Explain exclusions**: Why data excluded
- **Provide context**: Full background
- **Acknowledge limitations**: What's not known
- **Encourage scrutiny**: Invite verification

## Tools and Techniques
