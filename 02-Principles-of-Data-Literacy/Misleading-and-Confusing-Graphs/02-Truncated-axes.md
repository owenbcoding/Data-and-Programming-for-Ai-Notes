# Truncated Axes

## Understanding Truncated Axes
Truncated axes occur when the y-axis doesn't start at zero, potentially exaggerating differences between values and creating misleading impressions.

## How Truncation Misleads

### Visual Exaggeration
- Small differences appear large
- Changes seem more dramatic
- Trends appear steeper
- Comparisons exaggerated
- Impact overstated

### Example: Bar Chart Truncation
- Bars showing 45 vs. 50 with axis starting at 40
- Visual difference appears large
- Actual difference: 11% increase
- Visual impression: Much larger increase
- Misleading representation

### Example: Line Chart Truncation
- Temperature variation from 98.0°F to 98.6°F
- Axis from 97.5°F to 99.0°F
- Small variation appears dramatic
- May be appropriate for scientific precision
- Misleading for general audience

## When Truncation is Appropriate

### Acceptable Use Cases
- **Line charts**: Focus on change, not magnitude
- **Scientific data**: When zero is meaningless
- **Small variations**: When differences are important
- **Precision emphasis**: When small changes matter
- **Technical audiences**: Who understand the scale

### Scientific Context
- Laboratory measurements
- Temperature variations
- Pressure changes
- Chemical concentrations
- Physical measurements

### Time Series Focus
- Stock price changes
- Temperature trends
- Economic indicators
- Process monitoring
- Quality control

## When Truncation is Misleading

### Problematic Use Cases
- **Bar charts**: Always should start at zero
- **Magnitude comparisons**: When total size matters
- **General audiences**: May not understand scale
- **Political/advocacy**: Can be used to deceive
- **Financial presentations**: Can mislead investors

### Bar Chart Truncation
- **Never acceptable**: Bar charts must start at zero
- **Why**: Length represents magnitude
- **Impact**: Exaggerates differences
- **Solution**: Always start at zero
- **Alternative**: Use different chart type

### Public Communication
- News graphics
- Political advertisements
- Advocacy presentations
- Social media graphics
- General audience materials

## Best Practices for Truncated Axes

### Transparency
- **Clear indication**: Show axis doesn't start at zero
- **Break symbol**: Use visual break indicator
- **Explanation**: Explain why truncation used
- **Context**: Provide full context
- **Alternatives**: Show full-scale version

### Labeling
- **Axis labels**: Clear scale indication
- **Break marks**: Visual indication of truncation
- **Value labels**: Show actual values
- **Annotations**: Explain truncation
- **Legend**: Context for interpretation

### Alternative Presentations
- **Two charts**: One zoomed, one full scale
- **Inset**: Zoomed detail within full chart
- **Percentage change**: Show relative change
- **Callouts**: Highlight specific values
- **Tables**: Provide exact values

## Detecting Truncated Axes

### Visual Indicators
- **No zero**: Y-axis doesn't include zero
- **Break marks**: Jagged line or symbol
- **Suspicious differences**: Visual vs. numerical mismatch
- **Dramatic trends**: More dramatic than expected
- **Missing context**: Scale information unclear

### Verification Steps
- **Check axis labels**: Look for zero
- **Calculate actual differences**: Compare visual to numerical
- **Ask for full scale**: Request alternative presentation
- **Consider context**: Does truncation make sense?
- **Compare to benchmarks**: Known values for comparison

### Questions to Ask
- Why doesn't the axis start at zero?
- What would this look like with zero baseline?
- Is the truncation clearly indicated?
- What's the actual magnitude of differences?
- Is this appropriate for the audience?

## Handling Truncation in Practice

### Decision Framework
1. **Is zero meaningful?** If no, truncation may be appropriate
2. **What's the audience?** Technical vs. general
3. **What's the purpose?** Emphasis vs. accuracy
4. **Are there alternatives?** Different presentations
5. **Is it clearly indicated?** Transparency

### Implementation Steps
1. **Assess need**: Is truncation necessary?
2. **Choose presentation**: How to show truncation
3. **Add indicators**: Clear visual indicators
4. **Provide context**: Explain truncation
5. **Consider alternatives**: Other presentations

### Communication

- **Document decisions**: Record rationale
