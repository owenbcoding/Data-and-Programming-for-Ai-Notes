# Simplifying Statistics with Prompt Engineering: Coffee Shop Sales

## Project Overview
This project uses generative AI to simplify statistical analysis of coffee shop sales data, practicing prompt engineering skills to extract meaningful insights.

## Project Description
Use AI to analyze coffee shop sales data, formulating effective prompts to explore the data, calculate statistics, and draw conclusions while validating AI-generated results.

## Dataset Variables
- **Date**: Date of sales
- **Day of week**: Monday through Sunday
- **Time of day**: Morning, afternoon, evening
- **Product type**: Coffee, tea, pastry, etc.
- **Product name**: Specific product
- **Quantity**: Number sold
- **Price**: Unit price
- **Total sales**: Total revenue
- **Payment method**: Cash, card, mobile
- **Customer type**: New, returning

## Prompt Engineering Applications

### Initial Data Exploration
- **Prompt**: "Explore this coffee shop sales dataset and provide a summary of the key variables and their characteristics"
- **Goal**: Understand data structure and basic patterns
- **Validation**: Check summary against actual data
- **Refinement**: Ask for specific statistics if needed

### Statistical Calculations
- **Prompt**: "Calculate the mean, median, and standard deviation of daily sales for this coffee shop"
- **Goal**: Get central tendency and variability measures
- **Validation**: Manually calculate key statistics
- **Refinement**: Ask for step-by-step calculation

### Distribution Analysis
- **Prompt**: "Analyze the distribution of sales by product type and describe the patterns you find"
- **Goal**: Understand sales distribution across products
- **Validation**: Create visualizations to verify
- **Refinement**: Ask for specific patterns

### Relationship Analysis
- **Prompt**: "Analyze the relationship between time of day and sales, and describe any patterns you find"
- **Goal**: Understand temporal sales patterns
- **Validation**: Create time-based visualizations
- **Refinement**: Ask for specific time-based patterns

### Group Comparisons
- **Prompt**: "Compare sales between new and returning customers, and identify any significant differences"
- **Goal**: Understand customer behavior differences
- **Validation**: Calculate statistics manually
- **Refinement**: Ask for statistical significance

## Prompt Best Practices

### Clear Context
- **Data description**: Always describe the data
- **Analysis goal**: Clearly state what you want
- **Context**: Provide relevant context
- **Constraints**: Specify any constraints
- **Output format**: Specify desired output format

### Iterative Refinement
- **Start broad**: Begin with broad questions
- **Refine based on responses**: Narrow down based on AI responses
- **Ask for clarification**: When responses are unclear
- **Request verification**: Ask AI to verify its work
- **Build systematically**: Build analysis systematically

### Validation Focus
- **Always verify**: Always verify AI calculations
- **Cross-check**: Cross-check with manual calculations
- **Visual validation**: Create visualizations to verify
- **Question assumptions**: Question AI assumptions
- **Check for errors**: Check for calculation errors

## Common AI Interaction Challenges

### Hallucination
- **Issue**: AI making up data or results
- **Detection**: Check against actual data
- **Solution**: Always verify with actual data
- **Prevention**: Provide clear data context

### Misinterpretation
- **Issue**: AI misinterpreting data structure
- **Detection**: Results don't match expectations
- **Solution**: Clarify data structure in prompts
- **Prevention**: Provide data schema

### Calculation Errors
- **Issue**: AI making calculation mistakes
- **Detection**: Manual verification
- **Solution**: Ask for step-by-step calculations
- **Prevention**: Request verification

### Overgeneralization
- **Issue**: AI overgeneralizing from limited data
- **Detection**: Conclusions seem too broad
- **Solution**: Ask for specific evidence
- **Prevention**: Specify scope limitations
