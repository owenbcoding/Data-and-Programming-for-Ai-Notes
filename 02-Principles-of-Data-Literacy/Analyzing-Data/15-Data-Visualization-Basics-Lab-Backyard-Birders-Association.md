# Data Visualization Basics Lab: Backyard Birder's Association

## Project Overview
This lab applies data visualization principles to create effective visualizations for the Backyard Birder's Association, practicing the skills learned in the Data Visualization Basics module.

## Project Description
Create a series of data visualizations for the Backyard Birder's Association to communicate bird watching data effectively to different audiences.

## Dataset Variables
- **Bird species**: Species of bird observed
- **Date**: Date of observation
- **Location**: Location within backyard
- **Time of day**: Morning, afternoon, evening
- **Observer**: Person who made the observation
- **Count**: Number of birds observed
- **Behavior**: Bird behavior (feeding, singing, etc.)
- **Weather conditions**: Weather during observation
- **Habitat type**: Type of habitat (feeder, bath, etc.)
- **Season**: Season of observation

## Visualization Projects

### Project 1: Species Distribution
- **Purpose**: Show which bird species are most common
- **Chart type**: Bar chart or pie chart
- **Data**: Bird species counts
- **Audience**: General bird watchers
- **Goal**: Help members understand common species

### Project 2: Temporal Patterns
- **Purpose**: Show how bird observations vary over time
- **Chart type**: Line chart or time series
- **Data**: Observations over time
- **Audience**: Association leadership
- **Goal**: Identify seasonal patterns

### Project 3: Habitat Analysis
- **Purpose**: Show which habitats attract most birds
- **Chart type**: Bar chart or stacked bar chart
- **Data**: Birds by habitat type
- **Audience**: Members interested in habitat improvement
- **Goal**: Guide habitat enhancement

### Project 4: Weather Impact
- **Purpose**: Show how weather affects bird observations
- **Chart type**: Grouped bar chart or heat map
- **Data**: Observations by weather condition
- **Audience**: Scientific bird watchers
- **Goal**: Understand environmental influences

### Project 5: Member Contributions
- **Purpose**: Show contributions by different observers
- **Chart type**: Bar chart or treemap
- **Data**: Observations by observer
- **Audience**: Association members
- **Goal**: Recognize member contributions
