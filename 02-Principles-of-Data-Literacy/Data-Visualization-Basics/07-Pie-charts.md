# Pie Charts

## Understanding Pie Charts
Pie charts display data as a circle divided into slices, with each slice representing a category's proportion of the whole. They're used to show part-to-whole relationships.

## When to Use Pie Charts

### Appropriate Situations
- Showing part-to-whole relationships
- Few categories (ideally 3-5)
- Emphasizing proportions
- Simple composition display
- When approximate comparisons suffice

### Inappropriate Situations
- Many categories (use bar charts)
- Precise value comparison (use bar charts)
- Time series (use line charts)
- Ranking categories (use bar charts)
- Showing changes over time (use stacked bars)

## Types of Pie Charts

### Standard Pie Chart
- Basic pie chart
- Most common type
- Simple proportions
- Easy to understand
- Limited categories

### Donut Chart
- Pie with hole in center
- Modern aesthetic
- Space for summary text
- Same limitations as pie
- Design preference

### Exploded Pie Chart
- Slices separated from center
- Emphasizes specific slices
- Can be misleading
- Overused effect
- Generally discouraged

### Nested Pie Charts
- Multiple concentric pies
- Hierarchical data
- Complex interpretation
- Hard to read
- Generally avoid

## Design Best Practices

### Slice Limitation
- Maximum 5-7 categories
- Combine small categories as "Other"
- Too many slices unreadable
- Prioritize major categories
- Clear grouping strategy

### Ordering
- Logical ordering important
- Clockwise from largest
- Or natural ordering
- Consistent ordering
- Meaningful arrangement

### Color Usage
- Distinct colors for slices
- Colorblind-friendly palette
- Consistent color coding
- Avoid similar colors
- Use color purposefully

### Labels
- Clear slice labels
- Include percentages
- Legend or direct labels
- Avoid overlapping labels
- Readable text size

### 3D Effects
- Generally avoid 3D
- Distorts proportions
- Hard to read accurately
- Adds no value
- **Use 2D only**

## Common Mistakes

### Too Many Slices
- Hard to distinguish
- Labels overlap
- Small slices meaningless
- **Solution**: Combine categories, use bar chart

### 3D Effects
- Distorts perception
- Misleading proportions
- **Solution**: Always use 2D

### Inconsistent Ordering
- Random slice arrangement
- Hard to compare
- **Solution**: Order by size or logically

### Missing Percentages
- Hard to assess proportions
- **Solution**: Always include percentages

### Similar Colors
- Slices hard to distinguish
- **Solution**: Use distinct, accessible colors

## Creating Effective Pie Charts

### Data Preparation
- Calculate proportions/percentages
- Combine small categories
- Ensure data sums to 100%
- Prioritize major categories
- Prepare labels

### Chart Design
- Choose 2D pie chart
- Limit to 5-7 categories
- Select color palette
- Plan label placement
- Consider donut variant

### Implementation
- Set proper proportions
- Apply distinct colors
- Add clear labels
- Include percentages
- Add legend if needed

### Review and Refine
- Check readability
- Ensure accuracy
- Test with audience
- Simplify if needed
- Finalize design

## Alternatives to Pie Charts

### Bar Charts
- Better for comparison
- More categories possible
- Precise value reading
- Easier to interpret
- **Generally preferred**

### Stacked Bar Charts
- Show composition
- Compare across groups
- Easier to compare
- More flexible
- **Better alternative**

### Treemaps
- Hierarchical data
- Space-efficient
- Many categories
- Complex patterns
- **Specialized use**

### Waffle Charts
- Grid of squares
- Clear proportions
- Modern aesthetic
- Limited categories
- **Good alternative**

## Interpretation Guidelines

### Reading Pie Charts
- Compare slice sizes visually
- Read percentages for precision
- Focus on largest slices
- Understand composition
- Note "Other" category

### Comparison
- Compare proportions
- Identify dominant categories
- Note minor categories
- Assess balance
- Consider context

### Communication
- Explain composition
- Highlight key proportions
- Note category groupings
- Provide context
- Use clear language

## When Pie Charts Work

### Successful Use Cases
- Showing simple composition
- Emphasizing dominant category
- Non-technical audience
- Rough comparisons sufficient
- Few categories
- Aesthetic considerations

### Examples
- Market share by company
- Budget allocation
- Survey response distribution
- Demographic breakdown
- Sales by product category

## When to Avoid Pie Charts

### Problematic Situations
- Many categories
- Precise comparison needed
- Similar-sized categories
- Changes over time
- Scientific accuracy required
- Complex composition

### Better Alternatives
- Many categories → Bar chart
- Precise comparison → Bar chart
- Time series → Line chart
- Complex composition → Stacked bar chart
- Hierarchical data → Treemap

## Best Practices Summary

### Do
- Limit to 5-7 categories
- Use 2D only
- Include percentages
- Order slices logically
- Use distinct colors

### Don't
- Use 3D effects
- Include too many categories
- Use for precise comparison
- Order randomly
- Use similar colors

## Research and Expert Opinion

### Statistical Community
- Generally discouraged by statisticians
- Edward Tufte criticizes pie charts
- Hard to compare angles
- Human perception issues
- **Bar charts usually better**

### Design Considerations
- Can be effective for simple cases
- Aesthetic appeal
- Familiar to general public
- Can work for storytelling
- **Use judiciously**

### Communication Context
- Consider audience expertise
- Match to communication goal
- Simplify complex data
- Use appropriate for context
- **Prioritize clarity over aesthetics**
