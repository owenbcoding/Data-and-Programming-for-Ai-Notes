# Data Aggregation

## What is Data Aggregation?
Data aggregation is the process of gathering and expressing data in a summary form, typically for statistical analysis or business intelligence. It involves combining data from multiple sources or summarizing detailed data into higher-level insights.

## Types of Data Aggregation

### Temporal Aggregation
- Combining data over time periods
- Daily → weekly → monthly → yearly
- Time series summarization
- Trend analysis
- Seasonal adjustment

### Spatial Aggregation
- Combining geographic data
- Zip code → city → state → region
- Geographic summarization
- Regional analysis
- Mapping applications

### Categorical Aggregation
- Grouping by categories
- Combining detailed categories
- Hierarchical grouping
- Segment analysis
- Portfolio aggregation

### Statistical Aggregation
- Summarizing with statistics
- Mean, median, mode calculations
- Variability measures
- Distribution summaries
- Statistical analysis

## Aggregation Functions

### Sum and Count
- **Sum**: Total of numeric values
- **Count**: Number of observations
- **Weighted sum**: Values with weights
- **Running totals**: Cumulative sums
- **Unique count**: Distinct values

### Central Tendency
- **Mean**: Average value
- **Median**: Middle value
- **Mode**: Most frequent value
- **Weighted mean**: With importance weights
- **Trimmed mean**: Excluding extremes

### Variability
- **Standard deviation**: Spread measure
- **Variance**: Squared spread
- **Range**: Max - min
- **IQR**: Middle 50% spread
- **Percentiles**: Distribution points

### Extremes
- **Minimum**: Smallest value
- **Maximum**: Largest value
- **First/last**: Time-based extremes
- **Top N**: Highest values
- **Bottom N**: Lowest values
