# Checking AI-Generated Calculations

## The Importance of Verification
AI can make calculation errors, so it's essential to verify all statistical calculations independently before relying on results for important decisions.

## Common Calculation Errors

### Arithmetic Errors
- Simple arithmetic mistakes
- Incorrect formula application
- Calculation order errors
- Rounding errors
- Unit conversion mistakes

### Formula Application Errors
- Wrong formula for situation
- Incorrect parameter usage
- Missing or extra terms
- Wrong distribution assumptions
- Inappropriate statistical tests

### Data Entry/Interpretation Errors
- Misreading provided data
- Incorrect data parsing
- Wrong variable identification
- Misunderstanding data structure
- Format interpretation errors

## Verification Strategies

### Manual Verification
- Recalculate by hand for small datasets
- Use calculator for key steps
- Verify intermediate results
- Check final calculations
- Document verification process

### Software Verification
- Use Excel/Google Sheets
- Statistical software (R, SPSS, SAS)
- Python libraries (NumPy, SciPy, pandas)
- Online calculators
- Specialized statistical tools

### Cross-Method Verification
- Calculate using different methods
- Compare parametric vs. non-parametric
- Use alternative formulas
- Verify with different software
- Check consistency across approaches

## Step-by-Step Verification Process

### 1. Understand the Calculation
- What calculation was performed?
- What formula was used?
- What assumptions were made?
- What data was used?
- What was the expected result?

### 2. Verify Input Data
- Check data was provided correctly
- Verify data format and structure
- Confirm variable identification
- Check for data entry errors
- Validate data ranges

### 3. Verify Method Choice
- Is the method appropriate for data type?
- Are assumptions met?
- Is sample size sufficient?
- Are there better alternatives?
- Is the calculation standard practice?

### 4. Recalculate Independently
- Use different tool/method
- Follow step-by-step process
- Document your calculation
- Compare results
- Investigate discrepancies

### 5. Interpret and Validate
- Do results make sense?
- Are they consistent with expectations?
- Are there any red flags?
- Do they align with domain knowledge?
- Are practical considerations met?

## Specific Verification by Calculation Type

### Mean Calculation
- Sum all values and divide by count
- Verify count is correct
- Check for data entry errors
- Consider outlier effects
- Compare with median

### Standard Deviation
- Verify mean calculation first
- Check squared deviations
- Verify division by n or n-1
- Compare with range
- Check calculation steps

### Correlation Coefficient
- Verify data pairing
- Check covariance calculation
- Verify individual SDs
- Compare with scatter plot
- Check for outliers

### Hypothesis Tests
- Verify test statistic calculation
- Check degrees of freedom
- Verify p-value calculation
- Compare with critical values
- Check assumption compliance

## Prompting for Verification

### Self-Check Prompts
- "Please double-check your calculation"
- "Verify each step of your calculation"
- "Show your work step by step"
- "Check for any calculation errors"
- "Recalculate using a different method"

### Cross-Check Prompts
- "Calculate this using an alternative method"
- "What would the result be using formula X?"
- "Verify this calculation against standard formulas"
- "Check if this result is consistent with theory"
- "Calculate using different software logic"

### Explanation Prompts
- "Walk through your calculation step by step"
- "Explain which formula you used and why"
- "Show the intermediate calculations"
- "Explain any assumptions you made"
- "Detail your calculation process"

## Red Flags for Calculation Errors

### Result Suspicious
- Result doesn't match expectations
- Value seems too large or too small
- Doesn't align with similar calculations
- Contradicts domain knowledge
- Seems too precise or convenient

### Process Concerns
- AI skips explanation of steps
- Formula not specified
- Assumptions not stated
- Method not justified
- Calculation seems rushed

### Data Issues
- AI misinterprets data format
- Wrong variables used
- Data range violations
- Sample size inconsistencies
- Missing data mishandled

## Best Practices

### Before AI Calculation
- Understand what you need calculated
- Know the appropriate method
- Have rough estimate of expected result
- Prepare data in clear format
- Plan verification approach

### During AI Interaction
- Request step-by-step calculations
- Ask for formula specification
- Request assumption checking
- Ask for alternative methods
- Document the process

### After AI Calculation
- Always verify independently
- Use different tools/methods
- Check against domain knowledge
- Validate with known examples
- Document verification results

### Documentation
- Record AI calculation
- Document verification method
- Note any discrepancies
- Keep calculation records
- Maintain reproducibility
