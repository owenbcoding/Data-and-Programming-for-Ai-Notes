## Common Mistakes to Avoid

### Calculation Errors
- Not specifying sample vs. population SD
- Not using Bessel's correction for samples
- Including invalid data in calculation
- Not verifying calculations manually
- **Always**: Check which SD formula is appropriate

### Interpretation Errors
- Assuming SD always indicates normality
- Over-interpreting small SD differences
- Ignoring distribution shape
- Not considering sample size impact
- **Always**: Examine full distribution

### Application Errors
- Using SD with inappropriate data types
- Applying SD to ordinal data
- Not checking for outliers' influence
- Using SD when robust measures needed
- **Always**: Match measure to data characteristics

## Troubleshooting

### AI Makes Calculation Errors
- Request step-by-step breakdown
- Provide data in different format
- Ask AI to verify its own work
- Cross-check with manual calculation
- Specify sample vs. population clearly

### Results Don't Make Sense
- Re-examine data for errors
- Check if data was provided correctly
- Ask AI to explain its reasoning
- Verify data is appropriate for SD
- Consider alternative measures

### Interpretation Unclear
- Ask for simpler explanation
- Request real-world examples
- Ask for analogy
- Request visual representation
- Break down into components
