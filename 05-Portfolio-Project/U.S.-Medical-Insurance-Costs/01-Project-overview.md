# Project Overview

The U.S. Medical Insurance Costs project is a portfolio project that applies Python fundamentals to analyze medical insurance data.

## Project Description
Analyze a dataset of medical insurance costs to understand factors that influence insurance charges.

## Project Goals
- Apply Python fundamentals learned in previous units
- Practice data analysis with Python
- Explore relationships between variables
- Draw insights from real data
- Build a portfolio-worthy project

## Dataset Variables
- Age: Age of the insured person
- Sex: Gender (male/female)
- BMI: Body Mass Index
- Children: Number of children
- Smoker: Smoking status (yes/no)
- Region: Geographic region
- Charges: Insurance charges

## Learning Outcomes
- File reading and data loading
- Data cleaning and preparation
- Statistical analysis
- Data visualization
- Insight generation
