## Concept Flashcards

### Data Literacy Terms
- **Structured Data**: Data organized in a fixed format (like spreadsheets, databases)
- **Unstructured Data**: Data without predefined format (like text, images, audio)
- **Data Quality**: How fit data is for its intended use
- **Data Bias**: Systematic error in data that leads to unfair outcomes
- **Missing Data**: Absence of values in a dataset
- **Outliers**: Data points that differ significantly from other observations
